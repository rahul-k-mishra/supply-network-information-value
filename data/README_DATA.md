# Dataset

The network topologies come from

    Willems, S.P. (2008). Data set -- real-world multiechelon supply chains
    used for inventory optimization. Manufacturing & Service Operations
    Management 10(1), 19-23. DOI 10.1287/msom.1070.0176

The workbook is an INFORMS/MSOM electronic supplement and is not
redistributed here. Download it from the publisher and save it in this
folder as

    data/chain_data.xlsx

Everything else the experiments use -- latent supplier identities, risk
attributes, probe outcomes, disruption probabilities -- is generated by the
model in this repository, not observed.
